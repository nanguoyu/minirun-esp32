# Changes

## 0.1.0

First public release.

- LFM2.5-230M runs on an ESP32-S3 with SD model storage.
- Two CPU cores overlap reading and computation.
- Up to 1024 context positions with FP32 conversation cache on SD.
- USB text client with automatic port detection and an LCD reply display.
- Host setup, hardware guide, and builds for macOS, Linux, and ESP32.
